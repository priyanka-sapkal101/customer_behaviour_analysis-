# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across multiple product categories. The objective is to identify spending patterns, customer segments, product preferences, discount usage, and subscription behavior to support data-driven business decisions.

The project combines Python for data cleaning and exploratory data analysis, SQL for business analysis, and Power BI for interactive visualization.

## Tools & Technologies

- **Python** — Data cleaning and exploratory data analysis
- **Pandas** — Data manipulation and preprocessing
- **SQL (PostgreSQL)** — Business queries and analysis
- **Jupyter Notebook** — Python development environment
- **Power BI** — Interactive dashboard and visualization

## Dataset Overview

The dataset contains 3,900 rows and 18 columns.

Key features include:

- **Customer demographics:** Age, gender, location, subscription status
- **Purchase details:** Item purchased, category, purchase amount, season, size, color
- **Shopping behavior:** Discounts, promo codes, previous purchases, purchase frequency, review ratings, shipping type

The dataset initially contained 37 missing values in the `review_rating` column.

## Project Workflow

### 1. Data Loading and Exploration

- Imported the dataset using Pandas.
- Examined the dataset structure using `df.info()`.
- Generated summary statistics using `df.describe()`.
- Checked missing values and data consistency.

### 2. Data Cleaning and Preprocessing

- Handled missing review ratings using the median rating of each product category.
- Standardized column names to snake_case for readability.
- Created an `age_group` feature by grouping customer ages.
- Created a `purchase_frequency_days` feature.
- Checked the relationship between `discount_applied` and `promo_code_used`.
- Removed the redundant `promo_code_used` column.

### 3. SQL Business Analysis

The cleaned data was loaded into a SQL database for structured analysis. The following business questions were explored:

1. **Revenue by Gender:** Compared total revenue generated by male and female customers.
2. **High-Spending Discount Users:** Identified customers who used discounts and spent above the average purchase amount.
3. **Top 5 Products by Rating:** Identified products with the highest average review ratings.
4. **Shipping Type Comparison:** Compared average purchase amounts for Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers:** Compared customer counts, average spending, and total revenue by subscription status.
6. **Discount-Dependent Products:** Identified products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Classified customers as New, Returning, or Loyal based on purchase history.
8. **Top 3 Products per Category:** Ranked the most purchased products within each category.
9. **Repeat Buyers and Subscriptions:** Examined subscription status among customers with more than five purchases.
10. **Revenue by Age Group:** Calculated revenue contributions across customer age groups.

These queries demonstrate practical SQL skills, including filtering, aggregation, grouping, sorting, and ranking.

### 4. Power BI Dashboard

An interactive Customer Behavior Dashboard was developed to present key metrics and trends.

Dashboard highlights:

- Total customers
- Average purchase amount
- Average review rating
- Customer distribution by subscription status
- Revenue by product category
- Sales by product category
- Revenue by age group
- Sales by age group

Interactive filters allow users to explore customer behavior by subscription status, gender, category, and shipping type.

## Key Findings

- The dataset contains **3,900 customer purchase records**.
- The overall average purchase amount shown on the dashboard is approximately **$59.76**.
- The average review rating shown on the dashboard is **3.75**.
- Non-subscribers account for a larger share of customers and total revenue than subscribers in this dataset.
- Express shipping customers have a higher average purchase amount than Standard shipping customers in the SQL results.
- The analysis identifies products with high average ratings and products with a high proportion of discounted purchases.
- Customer segmentation highlights New, Returning, and Loyal customer groups.

## Business Recommendations

Based on the analysis, the following actions could help improve business performance:

- **Boost subscriptions:** Promote exclusive benefits to encourage customers to subscribe.
- **Improve customer loyalty:** Reward repeat purchases and strengthen customer retention.
- **Review discount policies:** Evaluate discount effectiveness while protecting profit margins.
- **Optimize product positioning:** Promote highly rated and best-selling products.
- **Target marketing campaigns:** Focus on relevant customer age groups and shopping preferences.
- **Evaluate shipping options:** Use purchasing patterns to assess the value of Express shipping.

## How to Run the Project

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required Python library:

   ```bash

   ```

6. Load the cleaned dataset into your SQL database and execute the business queries.
7. Open the Power BI `.pbix` file to explore the dashboard.
